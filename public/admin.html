Лобби — ученики входят
  1. Что такое фронтенд. Всё, что вы видите на сайте и нажимаете: кнопки, цвета, тексты, анимации — это фронтенд.
  2. Фронтенд и бэкенд. Ресторан: бэкенд — кухня (готовит, хранит продукты = данные). Фронтенд — зал, меню и официант: то, что видит гость.
  3. Из чего сделан сайт. HTML — скелет (что есть на странице). CSS — одежда (как выглядит). JavaScript — мышцы (движение и логика). Сегодня трогаем HTML и CSS.
  4. Демо: нажмите «🦴 Выключить CSS у всех» — у всех сайт станет «голым». Включите обратно: «Вот что делает CSS».
  5. Работа с заказчиком. Фронтендеру приходят правки: «поменяй цвет», «тут баг». Сейчас к вам придёт настоящий заказчик → Выпустить заказчика.
  1. Ориентир — 3–4 минуты на заказ. Смотрите на таблицу справа: зелёные готовы, оранжевым нужна помощь.
  2. Первый заказ покажите вместе: «Включите 🔍 Лупу и кликните по кнопке». Дальше пусть ищут сами.
  3. Если половина застряла — 💡 Подсказка всем (каждое нажатие — следующая ступенька).
  4. Перед багом (заказ 4) можно нажать 👀 Внимание и сказать: «Баг — это ошибка. Искать баги — работа программиста».
  5. Кто закончил раньше — получает доп. правки сам, ждать не скучно.
  1. Когда большинство сделали 5-й заказ — 🎉 Финал для всех. Заказчик скажет «Наконец-то!», у всех сертификаты.
  2. Спросите: «Какой цвет фона вы выбрали?» — пусть покажут соседям.
  3. «Сегодня вы сделали то, что фронтендеры делают каждый день: правки по просьбе заказчика, поиск бага, свой дизайн».
  4. Что дальше на курсе: JavaScript, свои проекты, портфолио, первые реальные заказы.
