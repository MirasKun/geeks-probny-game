# 🍔 Студия разработки — игра для пробного урока GEEKS

Ученик становится разработчиком бургерной «Burger Bro». Урок из двух этапов по 30 минут:

1. **Фронтенд.** Пиксельный заказчик приходит с правками, ученик меняет **HTML и CSS** сайта.
2. **Бэкенд.** Шеф просит добавить товары и принять заказ в панели управления, а потом у всех
   падает сервер, и ученик чинит ошибку в коде на **Python**.

Ассистент «Бит» подсказывает по ступенькам, преподаватель управляет темпом с пульта.
Настоящий Python не запускается: код проверяется как текст, поэтому ничего сломать нельзя.

Уже опубликовано:

- **Ученики:** <https://geeks-frontend.karabalta-bot.workers.dev>
- **Пульт преподавателя:** <https://geeks-frontend.karabalta-bot.workers.dev/admin#pin=2342>
  (PIN вводить не нужно, ссылка входит сама; сохраните её в закладки)

PIN лежит в `wrangler.jsonc` (`"ADMIN_PIN"`) и один и тот же для Cloudflare и ноутбука.
Ученикам ссылку на пульт не показывайте.

### История учеников

Во вкладке пульта **«История»** видны все, кто играл: дата, время, имя и результат по обоим
этапам (✓ — прошёл до конца). Кнопка «🔄 Новый урок» историю не стирает. Лишние записи
удаляются крестиком, а «⬇ Скачать для Excel» сохраняет список в таблицу.

Если урок забыли закрыть, через 3 часа без действий следующий вход сам начнёт новый урок.

### Вход ученика

Имя и номер телефона (+996 и 9 цифр) обязательны: их спрашивают при каждом новом открытии сайта
и после «🔄 Новый урок». Перезагрузка вкладки их не спрашивает. Если ученик закрыл вкладку и снова
ввёл те же данные в том же браузере, он продолжит с того же места. Номера видны только на пульте,
в «Истории» и в файле для Excel.

### Сколько учеников выдержит

Проверено на живом сайте: 10 учеников одновременно, заказ доходит до всех примерно
за 0,15 секунды. Бесплатного тарифа Cloudflare хватает на десятки уроков в день.

## Вариант 1 — Cloudflare (рекомендуется)

Сайт живёт в интернете, ноутбук сервером не нужен. Бесплатного тарифа хватает.

`npx wrangler login` нужен **один раз на компьютере**: дальше Cloudflare запоминает вход.
Повторный `npx wrangler deploy` нужен, только если вы меняли файлы игры.

1. Зарегистрируйтесь на <https://dash.cloudflare.com> (бесплатно).
2. По желанию поменяйте PIN в файле `wrangler.jsonc`: строка `"ADMIN_PIN"`.
3. В терминале, в папке проекта:

   ```bash
   npx wrangler login
   ```

   Откроется браузер — войдите в свой аккаунт Cloudflare и нажмите «Allow».

4. Опубликуйте:

   ```bash
   npx wrangler deploy
   ```

   В конце будет адрес вроде `https://geeks-frontend.ВАШ-НИК.workers.dev` — его и
   давайте ученикам. Ссылка постоянная: на следующем уроке просто нажмите
   «🔄 Новый урок» в пульте.

> Изменили задания или дизайн — снова выполните `npx wrangler deploy`.

### Автоматическая публикация из GitHub

Код лежит в <https://github.com/MirasKun/geeks-probny-game>. Cloudflare уже подключён:
каждый push в ветку `main` сам публикует сайт за 1–2 минуты, `wrangler` запускать не нужно.
Ход публикации виден в Cloudflare: **Workers & Pages** → `geeks-frontend` → **Deployments**.

## Вариант 2 — ноутбук преподавателя (без интернета)

Все в одной Wi-Fi сети. В папке проекта:

```bash
node server.js
```

В консоли напечатается адрес для учеников (например `http://192.168.1.177:3000`) и
адрес пульта `http://localhost:3000/admin` (PIN тот же, что в `wrangler.jsonc`).

Если ученики не открывают адрес — разрешите Node входящие подключения
(macOS спросит при первом запуске: нажмите «Разрешить»).

## Вариант 3 — совсем без сервера

Откройте `public/index.html` двойным кликом. Пульта не будет: заказы идут по очереди
сами, после выполнения появляется кнопка «Следующий заказ →». Этот же режим включается
автоматически, если связь с сервером пропала.

## План урока (этап 1: фронтенд, 30 минут)

| Минуты | Что происходит | Кнопки пульта |
|---|---|---|
| 0–7 | Рассказ: что такое фронтенд, HTML = скелет, CSS = одежда | «🦴 Выключить CSS у всех» — демо |
| 7–25 | Игра: 3 заказа, ~5–6 минут на каждый | «🧑‍🍳 Следующий заказ», «💡 Подсказка всем», «👀 Внимание» |
| 25–30 | Финал этапа: «Наконец-то, мне нравится!» | «🎉 Закончить этап 1» |

## План урока (этап 2: бэкенд, 30 минут)

| Минуты | Что происходит | Кнопки пульта |
|---|---|---|
| 0–7 | Рассказ: сервер, база данных, запрос и ответ | «➡️ Перейти к этапу 2» |
| 7–25 | Игра: 3 заказа и авария примерно на 18-й минуте, после 2-го заказа | «🧑‍🍳 Следующий заказ», «🚨 Уронить сервер», «💡 Подсказка всем» |
| 25–30 | Финал: шеф доволен, общий сертификат за оба этапа | «🎉 Финал для всех» |

Шпаргалка с тезисами и ответы на каждый заказ — прямо в пульте.

### Заказы

1. **Оранжевая кнопка** — CSS `background`
2. **Баг: пропали кнопки** — найти `display: none`
3. **Свой дизайн** — цвет фона `body` на свой вкус → финал

Кто закончил раньше — получает доп. правки (опечатка, размер заголовка, углы карточек, цвет цен, шапка, новая карточка).

### Подсказки, подсветка и звук

- Нужный блок кода подсвечен жёлтым с самого начала заказа, после подсказки ярко горит точная строка.
- Неверно изменённая строка становится красной, и Бит говорит, что с ней сделать.
- На этапе 2 светится то, что нужно нажать, а «💡 Что делать?» называет следующий шаг.
- Пока печатается реплика, звучит голос шефа из `public/audio/chef-voice.mp3`. На длинной реплике запись
  повторяется с начала. Ученик выключает звук кнопкой 🔊, преподаватель — «🔇 Выключить звук».

### Заказы шефа (этап 2)

Сайт остаётся с дизайном ученика из этапа 1.

1. **Новый товар** — пицца за 450 сом, картинка перетаскивается с полки ассистента
2. **Новая цена** — Лимонад теперь 120 сом
3. **Первый заказ** — заказать пиццу на сайте и принять заказ в панели

**🚨 Авария** — по кнопке на пульте у всех падает сервер: на сайте ошибка 500, панель не работает,
счётчик ушедших клиентов растёт. В журнале сервера видно ошибку и номер строки. Чинится в
`server.py`: `return product` → `return products`. Кнопка на пульте может и отменить аварию.
Без сервера (автономный режим) авария случается сама после 2-го заказа.

Кто закончил раньше — получает доп. правки (снять картошку с продажи, свой товар, акция на чизбургер, новое название лимонада).

### Для тех, кто плохо печатает

- **Палитра цветов**: поставьте курсор на слово-цвет (например `gray`) и нажмите на кружок —
  слово заменится само.
- Кнопки-слова `px`, `none`, `block`… вставляют текст без набора на латинице.
- **↶ Отменить** и **⟲ Сбросить** — сайт невозможно сломать навсегда.

## Как поменять задания

- `public/js/starter.js` — стартовый HTML и CSS сайта бургерной.
- `public/js/tasks.js` — этап 1: тексты заказчика, подсказки, проверки и доп. правки.
- `public/js/backend-tasks.js` — этап 2: задания шефа, картинки на полке и код `server.py`.

## Устройство

```
public/            ← всё, что открывается в браузере
  index.html       ← экран ученика
  admin.html       ← пульт преподавателя
  js/student.js    ← логика игры (ученики её не видят и не трогают)
  js/backend.js    ← этап 2: панель магазина, заказы, журнал и авария
lib/room.js        ← состояние урока (общее для Cloudflare и ноутбука)
lib/hub.js         ← рассылка состояния ученикам и пульту
worker/index.js    ← Cloudflare Worker + Durable Object
server.js          ← запасной сервер для ноутбука, без библиотек
```
